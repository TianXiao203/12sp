## 交付物形态（用户问过两次，记牢）
**CI 产物只有裸内核 `Image`，没有 `boot.img`。** 这是刻意设计：只做 `make Image`。
`Image` 不能直接刷分区 —— 可刷的 boot 镜像需要 头部+内核+**ramdisk**+cmdline+dtb，
而 **ramdisk 只能来自 ROM**，造不出来。
- 路 A（推荐）：刷 AK3 zip —— AK3 本身就在做"读当前 boot 分区→换 kernel→重打包→写回"，
  与刷 boot.img 是同一个操作，且用当前 ramdisk。
- 路 B：用 `scripts/make-bootimg-via-adb.sh` 生成 `.img`（在手机上用 AK3 自带
  magiskboot 做 unpack/replace/repack），需要一个底（当前 boot 分区 dump）。
  ⚠️ `adb shell` 里**没有 su**（`su: inaccessible or not found`），
  所以 dump 当前 boot 分区得让用户在 ReSukiSU 管理器的 root 终端里跑：
  `dd if=/dev/block/by-name/boot_b of=/sdcard/boot_b_current.img bs=1M`

## 第二个必须修的问题：版本串会带 `-dirty`
`scripts/setlocalversion`（lineage-23.2）关键两段：
- 第 110~121 行：工作树有未提交改动就追加 `-dirty`

= **`5.10.260-gki-gef362912d37b`**，与设备完全一致，且不受 dirty / git 版本 / core.abbrev 影响。
